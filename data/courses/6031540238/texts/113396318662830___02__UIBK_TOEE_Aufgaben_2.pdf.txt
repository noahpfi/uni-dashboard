1 Das Feiglingsspiel
Bill und Ted spielen das Feiglingsspiel. Bill und Ted fahren auf einer einspurigen Strasse
mit hoher Geschwindigkeit aufeinander zu. Jeder von ihnen hat zwei Möglichkeiten:
ausweichen oder bleiben. Wenn ein Spieler ausweicht, blamiert er sich. Wenn beide
Spieler ausweichen, blamieren sich beide. Wenn beide bleiben, dann sterben sie beim
Zusammenstoss. Der Nutzen im Todesfall ist nur leicht geringer als der Nutzen aus einer
Blamage. Die Auszahlungsmatrix ist wie folgt:
Ted/Bill Bleiben Ausweichen
Bleiben -3,-3 2,0
Ausweichen 0,2 1,1
1. Finden Sie alle Nash Gleichgewichte in reinen Strategien.
2. Finden Sie alle Nash Gleichgewichte in gemischten Strategien.
3. Finden Sie für jedes Nash Gleichgewicht die Wahrscheinlichkeit, dass beide Spieler
das Feiglingsspiel überleben.

4 Papier-Stein-Schere
Betrachten Sie das Papier-Stein-Schere Spiel. Zwei Spieler wählen simultan ein Symbol.
Wenn beide dasselbe Symbol wählen, erhält jeder Spieler eine Auszahlung von 0. Wenn
sie unterschiedliche Symbole wählen, gewinnt Papier über Stein, Stein über Schere, und
Schere über Papier. Der Gewinner bekommt eine Auszahlung von 1, und der Verlierer
erhält eine Auszahlung von 1.

5 Statische Spiele - Wahlen
Es gebe drei Spieler S1, S2 und S3. Sie müssen eine Alternative A, B oder C wählen.
Jeder Spieler kann für eine Alternative stimmen. Jeder Spieler wählt also zwischen den
Strategien A, B und C. Die Alternative, welche die meisten Stimmen erhält, gewinnt.
Wenn keine Alternative eine Mehrheit erhält, gewinnt Alternative A. Ein Strategiepro…l
hat die Form (X;Y;Z) wobei X die Strategie von S1, Y die Strategie von S2 und Z die
Strategie von S3 ist. Die Auszahlungsfunktionen sind folgendermaßen:
Spieler S1:
Nutzen, wenn Alternative A gewinnt: 2
Nutzen, wenn Alternative B gewinnt: 1
Nutzen, wenn Alternative C gewinnt: 0
Spieler S2:
Nutzen, wenn Alternative A gewinnt: 0
Nutzen, wenn Alternative B gewinnt: 2
Nutzen, wenn Alternative C gewinnt: 1
Spieler S3:
Nutzen, wenn Alternative A gewinnt: 1
Nutzen, wenn Alternative B gewinnt: 0
Nutzen, wenn Alternative C gewinnt: 2
1. Gibt es eine Alternative X, für die folgendes gilt? Es gibt kein Nash Gleichgewicht
in reinen Strategien, so dass X in diesem Nash Gleichgewicht gewinnt.
2. Ist das Strategiepro…l (A;A;B) ein Nash Gleichgewicht?
3. Ist das Strategiepro…l (A;B;C) ein Nash Gleichgewicht?
4. Gibt es ein Nash Gleichgewicht, in dem ein Spieler eine gemischte Strategie wählt?
