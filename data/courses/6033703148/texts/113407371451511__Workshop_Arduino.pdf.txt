PS Software Engineering –Workshop Arduino Seite 8
Arduino Pins (I2C)
» I2C steht für Inter-Integrated-Circuits
» Wird verwendet, um Daten von einem oder mehreren Peripheriegerät(en) an einen Master zu
senden (unser Arduino)
» Verwendet zwei der Analogen Pins
A4 wird als SDA (Serial DAta) Pin verwendet
•
A5 wird als SCL (Serial CLock) verwendet
•
» Der Master fragt mittels Übermittlung der Adresse von dem Peripheriegerät nach Daten an.
Das Peripheriegerät übermittelt die Daten über den SDA.
•
SCL synchronisiert den Datenverkehr.
•
» Genaues Detailwissen wird nicht benötig, da
I2C für dieses Projekt nur im Hintergrund durch
Libraries verwendet wird
Dennoch muss man wissen, an welchem Pin
•
der Sensor angeschlossen werden muss

RGB LED
» Eine LED (Leuchtdiode) mit 3 verschiedenen Farbkanälen
Genauer genommen, 3 verschiedenfarbige LEDs in einem Plastikgehäuse, die sich einen
•
Masse-Pin teilen
» Dioden haben die Eigenschaft Strom nur in eine Richtung durchzulassen
Daher gibt es bei mehrfarbigen LEDs zwei Varianten
•
- Gemeinsame Anode: Die LEDs teilen sich einen (+)-Pol (meistens +3V3) und werden an 3
sendenden Eingängen angeschlossen. Wenn die Eingänge nicht senden, dienen sie als
Masse und der Stromkreis ist geschlossen.
- Gemeinsame Kathode: Ein Pin wird an die Masse des Arduinos angeschlossen, die
anderen Pins senden den benötigten Strom.
» Unsere LEDs:
haben eine gemeinsame Kathode
•
Sind eigentlich RBGs [R – B G]
•

RGB LED
» Dioden haben so gut wie keinen inneren Widerstand
• Strom wird unbegrenzt durchgelassen
• Daher müssen Widerstände zwischen allen 3 Polen vorangestellt werden.
• Rote LEDs verbrauchen weniger Spannung (Volt), daher werden stärkere Widerstände mit mehr Ohms
gebraucht
» Verkabelung und Code: https://learn.adafruit.com/adafruit-arduino-lesson-3-rgb-leds/overview
» Datensheet der LED: https://docs.rs-online.com/a4f6/0900766b8139d70e.pdf
» Wichtiger Hinweis: Die Widerstandsstärke muss so eingestellt werden, dass das Senden der gesamten 3.3V
durch den analogen Arduino Pin möglich ist
• Geringere Spannung bei den analogen Pins vom Arduino Nano wird nur durch PWM simuliert
Ø Gut zum Dimmen von LEDs aber nicht zum Verringern der Spannung, da teilweise immer die ganzen 3.3V
gesendet werden

Das Floating Pin Problem
» Wenn ein Pin im lesenden Modus ist,
aber dieser Pin nicht mit einem geschlossenen Stromkreis verbunden ist,
so befindet er sich in einem schwebenden / gleitenden Zustand
Das Lesen von dem Pin führt zu (beinahe zufälligen) HIGH und LOW Ausgaben
•
» Standardgemäß werden beim Arduino alle Pins auf Lesend mit hohem Widerstand gesetzt
void setup() {
Serial.begin(9600);
pinMode(D5, INPUT); //default mode
}
void loop() {
int val = digitalRead(D5);
Serial.println(val);
delay(100);
}

Das Floating Pin Problem beim Taster
» Solange der Stromkreis durch den Tastendruck geschlossen wird, liefert der lesende Pin
verlässlich die Spannung des Stromkreises zurück
LOW bei Anschluss an Ground
•
HIGH bei Anschluss an 3.3V
•
» Falls der Button jedoch nicht gedrückt wird, befindet sich der lesende Pin im gleitenden Modus
und liefert zufällige Ergebnisse
Button Button nicht

PS Software Engineering –Workshop Arduino Seite 27
Lösung Pull-Up Widerstände
» Dadurch das der lesende Pin mit einem 3.3V Pin verbunden wird, bleibt der lesende Zustand
stehts auf HIGH
Es wird ebenso ein hoher Widerstand (meistens 10kOhm) hinzugefügt
•
» Falls der Taster gedrückt wird, fließt der Strom zum geringsten Widerstand
Dies ist nicht mehr der VCC Pin, da dort ein hoher Widerstand dazwischen liegt
•
» Auf diese Art und Weise führt das Betätigen und nicht Betätigen des Tasters immer zu
zuverlässigen Werten
» Wenn anstelle des VCC der Ground Pin verwendet wird, um das Signal auf LOW zu halten, wird
von einem Pull-Down Widerstand gesprochen
PS Software Engineering –Workshop Arduino Seite 28
Geheimtipp: INPUT_PULLUP
» Der Arduino Nano 33 BLE kann seine Pins nicht nur auf INPUT und OUTPUT einstellen, sondern
besitzt auch einen INPUT_PULLUP Modus
» Damit muss nicht Umständlich mit externen Widerständen gearbeitet werden
void setup() {
Serial.begin(9600);
pinMode(D5, INPUT_PULLUP);
}
void loop() {
int val = digitalRead(D5);
Serial.println(val);
delay(100);
}
