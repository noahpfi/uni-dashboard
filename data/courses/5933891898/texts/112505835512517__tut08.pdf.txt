Functions 1/14
Deriving
• Instances for the following built in type classes can be automatically instantiated
with deriving:
• Eq, Ord, Enum, Bounded, Show, Read
• Derived Eq/Ord check for equality/order of constructors and recursively of the
arguments
• The order of constructors is determined by the order of declaration.
Example:
data Numbers = A Integer | B Integer deriving (Eq,Ord)
A a == A b = a == b
B a == B b = a == b
_ == _ = False
A a <= A b = a <= b
A _ <= B _ = True
...

Functions 5/14
Lambda (λ) Abstractions
• Allows us to create functions anywhere
• They are anonymous, which means the don’t clutter up the namespace.
• Often used with map or filter
• Syntax: \ pat1 ... patN -> expr
Examples:
myAbs (\x -> x^2-4) 0
(\x y -> x + y) 5 7
multWithTwo = \x -> x * 2

Functions 6/14
map and filter
map :: (a -> b) -> [a] -> [b]
• Takes a function f :: a -> b and list xs :: [a] as parameters
• Applies f to all elements in xs
• map f [a, b, ..., z] = [f a, f b, ..., f z]
map (*2) [1,2,3] == [2,4,6]
map head [[1,2],[2,3],[3,4]] == [1,2,3]
filter :: (a -> Bool) -> [a] -> [a]
• Takes a function f :: a -> Bool and list xs :: [a] as parameters
• Checks if f evalutes to True for all elements in xs
• if f a for an element a in xs evalutes to True, keep it, else discard it from the list.
filter (>=2) [1,2,3] == [2,3]
filter (==True) [True, False, True] == [True, True]

Exercise 8.2: Lambda-Abstractions, map and filter
Create a function div2 :: [Integer] -> [Integer] that filters out all integers not
divisible by two, and then divides them by two.
Use lambda abstractions wherever possible.
Hint: Use `mod`
Examples:
div2 [2,4,6] == [1,2,3]
div2 [1,2,3,4] == [1,2]
div2 [1,3,5] == []

Exercise 8.2: Possible Solution
div2 :: [Integer] -> [Integer]
div2 xs = map (\x -> x `div` 2) (filter (\x -> x `mod` 2 == 0) xs)
-- See "Partial Application" in the next slides
div2Advanced :: [Integer] -> [Integer]
div2Advanced xs = map (`div` 2) (filter even xs)

Functions 9/14
Partial Application
In Partial Application we do not to supply all arguments to a function.
• The consequence of that is the result of the partial application is a higher-order
function.
• Arguments can only be left out in order right-to-left (Exception: Operators).
Remember associativity of ->:
f :: a -> b -> c -> d
f :: a -> (b -> (c -> d))
By applying partially we "take away" -> from the left:
f x :: b -> (c -> d)
f x y == (f x) y :: c -> d

Functions 10/14
Partial Application (2)
Getting around the right-to-left restriction:
• flip, reverses order of arguments for binary functions.
• Lambda abstractions
Examples:
f :: a -> b -> c
f x :: b -> c
flip f x :: a -> c
g :: a -> b -> c -> d
g m n :: c -> d
(\x z y -> g x y z) m n :: b -> d
Exceptions: Operators
(3+) :: Num a => a -> a
(+3) :: Num a => a -> a
(`div` 2) :: Integral a => a -> a
