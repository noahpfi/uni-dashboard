Polymorphism 2/6
Parametric Polymorphism
So far:
add3 :: Integer -> Integer -> Integer -> Integer
add3 x y z = x + y + z
• Restricts use of function to one specific type.
Now:
add3 :: Num a => a -> a -> a -> a
add3 x y z = x + y + z
• a is type variable.
• Num a is type constraint on a, "type of a has to be a number".
• Without constraint Num a, addition in add3 would not be possible.
• Link to the Hackage Docs
• Other examples of type constraints built into Haskell are: Eq, Ord, Show, ...

Polymorphism 4/6
Exercise 4.2: Possible Solution
contains :: (Eq a) => List a -> a -> Bool
contains Empty _ = False
contains (Cons elem list) toMatch =
if elem == toMatch
then True
else contains list toMatch
Response to the question: We use == on the elements of the list, so they need an
instance for the == operator, and that is given by the Eq constraint.
