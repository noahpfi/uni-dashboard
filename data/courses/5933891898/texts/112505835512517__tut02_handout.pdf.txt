Expression to AST
• Not as easy, we need to know the types of all functions in the expression
• Consider expression: f 1 2 + 4
• If f is now defined as e.g. f x = x
• Expression is not syntactically valid!
• Therefore AST does not exist.
f +
1 2 4
• For e.g. f x y = x + y, expression is valid and AST can be derived:
+
f 4
1 2
• Important: functions have higher precedences than mathematical operators!

Data types: Enumerations
Example:
data Country = Austria | Germany | USA deriving Show
• data is the keyword
• Country is the new datatype’s name. First letter in Capitals.
• Austria, Germany, USA are the constructors. First letter in Capitals.
• deriving Show allows the new datatype to be displayed.
• The new datatype is an Enumeration: none of the Constructors have arguments.

Month -- month data type
