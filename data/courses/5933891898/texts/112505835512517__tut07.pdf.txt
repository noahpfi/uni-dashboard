Local Definitions: where / let ... in
• for local definitions
• not visible outside
• where can be used at fixed locations
• let ... in can be used everywhere
where vs let ... in:
circumference r = r^2*myPi where myPi = 3.1415
circumference r = let myPi = 3.1415 in r^2*myPi
More let ... in examples:
4 * (let a = 9 in a + 1) + 2
(let (a,b,c) = (1,2,3) in a+b+c) * 100

-- function with let ... in
surfaceCone1 :: Floating a => a -> a -> a
surfaceCone1 r s = let
base r = r^2 * pi
shell r s = r * s * pi
in base r + shell r s
-- function with where
surfaceCone2 :: Floating a => a -> a -> a
surfaceCone2 r s = base r + shell r s where
base r = r^2 * pi
shell r s = r * s * pi

Case expression
Allow for pattern matching in right-hand side of function.
case expr of
pat1 -> expr1
...
patN -> exprN
• expr is matched against pat1 to patN top to bottom.
• Sensitive to white-space!
• patI -> exprI must all be indented, and the same amount.

Type Classes
• Type Classes allow us to overload functions.
• Overloading means different implementations are provided for the same function
with different type signature.
• Types that implement a type class provide these overloaded functions.
class (TClass1 a, ..., TClassN a) => TCName a where
f1 :: Type
f1 = whatever --optional default implementation
f2 :: Type -- no default implementation
...
• Providing implementations for defined functions is optional
• Type Class constraints are also optional
• We are allowed to use functions specified in the type class or in the constraints in
our default implementations.

Type Class Instancing
To implement a type class for a type is we have to instantiate the type class as follows:
instance (TClassI a1, ...) => TClass (TConstr a1 ...) where
... -- implementation of functions
Example:
data Tree a = Node (Tree a) a (Tree a)
| Leaf
instance (Eq a) => Eq (Tree a) where
Leaf == Leaf = True
...

Exercise 7.3: Instancing for datatype
The following datatype is given:
data Money = OneCent | FiftyCent | OneEuro
Make Money an instance of Ord.
Tip: Look up the definition of Ord on hoogle.

Exercise 7.3: Possible Solution
-- We need to have Eq on Money, since Ord needs that,
-- so we have to define that too
instance Eq Money where
OneCent == OneCent = True
FiftyCent == FiftyCent = True
OneEuro == OneEuro = True
_ == _ = False
