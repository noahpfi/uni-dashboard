Working with the Terminal
Input Explanation
cd .. Go to parent directory
cd /usr/local Change current directory to /usr/local/
ls (-l) List files (detailed info)
Tab key Autocomplete directory/file name
Up/Down arrow keys Browse through last used commands
touch file Create file (works for MacOS and Linux)
chmod +x file Make file executable (works for MacOS and Linux)
rm file Remove file

GHCI commands (excerpt)
Command Shorthand Explanation
:load file :l Load script file
:reload :r Reload current script
:edit :e Edit current script
:edit file :e Edit file
:set property - Change GHCI settings, e.g. :set editor nano
:type expression :t Gives type information about expression, e.g. :type
myMult
:? / :help - Lists all available commands
:quit :q Exit GHCI

Exercise 1.1: Write code and run it
• Create a file tut-1-1.hs
• Use an editor to implement the equations given below as functions
• Load and test h(x) with values 0, 30, 70, 100 for x.

g(x) = 5x
h(x) = f(x)−g(x)
