Exercise 12.1: Implement Stack
Create a new module and implement the following functions and types:
• Create a new type Stack
• top: returns the top element of the stack
• pop: removes the top element and returns the new stack
• push: adds an element on top of the stack
• isEmpty: returns a Bool wheter the stack contains elements or not
Only export the 4 functions, the Stack type and a function to create an empty stack,
don’t export the Stack datatype constructor, to entirely hide the internal structure of
the stack.

Exercise 12.1: Possible Solution
module StackModule (top, pop, push, isEmpty, Stack, newStack) where
newtype Stack a = Stack [a] deriving (Show)
-- here you can also use Maybe instead of an error if nothing is on top,
-- but for simplicity I chose just to go with the error approach
top :: Stack a -> a
top (Stack []) = error "kein Element vorhanden"
top (Stack (x : xs)) = x
pop :: Stack a -> Stack a
pop (Stack []) = error "kein Element vorhanden"
pop (Stack (x : xs)) = Stack xs

push :: a -> Stack a -> Stack a
push x (Stack xs) = Stack (x : xs)
isEmpty :: Stack a -> Bool
isEmpty (Stack []) = True
isEmpty _ = False

newStack :: Stack a

Exercise 12.3: Possible Solution
printStack :: (Show a) => Stack a -> IO ()
printStack (Stack (x : xs)) = printStack2 "#" (Stack (x : xs))
where
printStack2 aux (Stack (x : xs)) = do
putStrLn (aux ++ show x)
if null xs then putStrLn "END"
else printStack2 (aux ++ "#") (Stack xs)
saveStack :: (Show a) => a -> IO ()
saveStack stack = do
appendFile "save.txt" (show stack ++ "\n")
