Exercise 5.2: Tuples
The determinant of a 2 × 2 matrix is defined as:
" #!
a b
det = ad −bc a,b,c,d ∈ R
c d
Implement the function detMat2, which takes as input a tuple consisting of two
tuples of numbers (first row, second row), and returns the determinant of the 2 × 2
matrix. Try to use type synonyms.
Tutorium—FunctionalProgramming WS25—Week05—TypeSynonyms AdamPescoller 2/7
Exercise 5.2: Possible Solution
-- some type synonyms, for better convenience
type Row a = (a, a)
type Matrix a = (Row a, Row a)
-- the function that gets the determinant from a matrix
detMat2 :: (Num a) => Matrix a -> a
detMat2 ((a, b), (c, d)) = a * d - b * c

Exercise 5.3: Type synonyms, Tuples, and show
Create new Type synonym Vector for (Double, Double).
Use Vector to implement the following three functions:
" # " # " #
a c a+c
• Vector addition (addV): + =
b d b+d
" # " #
a l ∗a
• Scalar multiplication (sMultV): l ∗ =
b l ∗b
• a function (printV) to visualize the Vector in the following way:
(a,b) → "Pair(a,b)"
Evaluate the following expression step-wise by hand and with the written code:
printV (addV (1,2) (sMultV 4 (addV (1,1) (3,3))))
Tutorium—FunctionalProgramming WS25—Week05—TypeSynonyms AdamPescoller 4/7
Exercise 5.3: Possible Solution
type Vector a = (a, a)
-- add two Vectors
addV :: (Num a) => Vector a -> Vector a -> Vector a
addV (a, b) (c, d) = (a + c, b + d)
-- multiply a scalar with a Vector
sMultV :: (Num a) => a -> Vector a -> Vector a
sMultV l (a, b) = (l * a, l * b)
-- print a Vector, we need the Show constraint to show the Tuple / Vector
printV :: (Show a, Num a) => Vector a -> String
printV v = "Pair" ++ show v
