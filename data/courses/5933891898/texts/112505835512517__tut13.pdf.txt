Remainder: List comprehension
• Offer ability to define lists similarly to set notation.
• Syntax [e | qual1, qual2,...], with qual_i consisting of:
• Generators: These give us the elements to base our list off.
Shape: pat <- expr, expr must return a list.
• Guards: Boolean expressions that filter elements.
• Local declarations: with let.
{2n|0 ≤ n ≤ 10∧n ̸= 3}
↓
[2^n | n <- [0..10], n /= 3]
↓
[1,2,4,16,32,64,128,256,512,1024]

Exam 1/5
Exercise 13.1: List Comprehension
Create a function f :: [Integer] -> [Integer] -> [(Integer, Integer)] that
takes two lists, xs and ys as input, and returns a list of tuples.
A tuple (x,y) is added to the returned list if 2x = y, with x ∈ xs and y ∈ ys.
Use list comprehensions to implement f.
Tutorium—FunctionalProgramming WS25—Week13—RecapandPractice AdamPescoller
Exam 2/5
Exercise 13.1: Possible Solution
f :: [Integer] -> [Integer] -> [(Integer,Integer)]
f xs ys = [ (x,y) | x <- xs, y <- ys,
let double x y = 2*x == y, double x y ]
