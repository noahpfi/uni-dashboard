Monad
Monad is a typeclass providing the following functions:
• (>>=) :: Monad m => m a -> (a -> m b) -> m b
• called bind
• Usage: expr1 >>= expr2
• bind extracts value of type a from expr1 and passes it to expr2 as parameter.
• (>>) :: Monad m => m a -> m b -> m b
• called then
• Usage: expr1 >> expr2
• then doesn’t pass value of expr1 to expr2.
• return :: Monad m => a -> m a
• Inject a value into the monadic type.
• Not to be confused with return in imperative programming.

IO Monad
• Available as standard, via Prelude
• Since Haskell is usually pure, the IO Monad is used to create side effects.
A few functions for interaction:
System.Environment.getArgs :: IO [String] -- get command line arguments
putChar :: Char -> IO () -- print character
putStr :: String -> IO () -- print string
putStrLn :: String -> IO () -- print string followed by newline
getChar :: IO Char -- read single character from stdin
getLine :: IO String -- read line (no newline-character in result)
IO () is used for IO actions without return data.

Do-Notation
With Do-Notation:
main = do
let greet = "Hello, what's your name?"
putStrLn greet
name <- getLine
putStrLn ("Hey " ++ name ++ ", you rock!")
Without Do-Notation:
main =
let greet = "Hello, what's your name?" in putStrLn greet >>
getLine >>= \name -> putStrLn ("Hey " ++ name ++ ", you rock!")
Note let x = expr vs x <- act
• let x = expr is for non-monadic assignments of variables.
• Can be transformed into monadic: x <- return expr

Exercise 11.1: Possible Solution
getGender :: IO String
getGender = do
gender <- getLine
if gender `elem` ["f", "m", "d"]
then return gender
else do
putStrLn "Please enter either f, m or d for your gender!"
getGender -- loop until we get a correct gender
