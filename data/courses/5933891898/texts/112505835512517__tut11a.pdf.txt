Modules
• To organize code
• Are a collection of functions, types and type classes
• The module Prelude is included by default
• Contains all the built-in functions we’ve been using so far
Syntax:
• Create module: module MyModule(x,y,z) where
• Import everything from a module: import MyModule
• Import something specific: import MyModule(x,y,z)
• Qualified import: import qualified MyModule
• Helps avoiding name conflicts by requiring use of Module name to use
function/type/etc.: MyModule.testFunction
• Exclude someting of a module:
import MyModule hiding (x,y,z)

Exercise 11.1: Possible Solution
type Coordinate = (Double, Double)
scalarAdd :: Coordinate -> Coordinate -> Coordinate
scalarAdd (x_1, y_1) (x_2, y_2) = (x_1 + x_2, y_1 + y_2)
scalarProduct :: Double -> Coordinate -> Coordinate
scalarProduct a (x, y) = (a * x, a * y)
euclidNorm :: Coordinate -> Double
euclidNorm (x, y) =
let zs = x ^ 2 + y ^ 2 in sqrt zs

Exercise 11.2: Possible Solution
import Coordinates (Coordinate, scalarAdd, scalarProduct)
centerOfMass :: [Coordinate] -> Coordinate
centerOfMass xs = scalarProduct (1 / fromIntegral (length xs))
$ foldr1 scalarAdd xs

Exercise 11.3: Scopes
Analyse the following code. Can you find errors or code with potentially unintended
effects?
import Prelude hiding(head)
konst = 4.0
func1 :: String -> Char
func1 xs = head xs
func2 :: Double -> Double
func2 x = pi * x
func3 :: (Double, Double) -> Double
func3 (x, y) = let myMult = x * konst; myAdd = x + konst in
myMult + myAdd
func4 = myMult * myMult
func5 :: Double -> Double
func5 konst = konst * 5
